The Love♥

A simple joke utility that does only one thing — after launching, it outputs the phrase «I love you!» to the console.

Простая шуточная утилита, которая делает только одно — выводит в консоль фразу «Я люблю тебя!».

Download latest release View on GitHub

Usage

console
$ love
I love you!

$ love Jane
I love you, Jane!

$ love Карен
Я люблю тебя, Карен!

The system locale is detected automatically — English and Russian are built in. On Windows, the console code page is switched to UTF-8 automatically.

Features

  • Written in Zig — requires Zig 0.17.0 or later
  • Locale-aware — localizes the output automatically (English and Russian built in)
  • Cross-platform — Linux, Windows and macOS (x86_64 and aarch64 for macOS)
  • Tiny — built with ReleaseSmall
